Notes techniques

• CSS isolé sous #fpr-map → n'impacte pas le reste du site.
• Three.js + GSAP/ScrollTrigger chargés en CDN (jsdelivr) — standard.
• Police Sweet Sans Pro via Adobe Fonts (déjà présente sur le site).
• Reflets (HDRI) : fichier public three.js.
• Animation pilotée par ScrollTrigger (pin). Si un smooth-scroll global est actif (Lenis, etc.), prévoir ScrollTrigger.refresh() / vérifier la compat.
• Hauteur de la section réglable : #fpr-map { height: clamp(360px,54vh,600px) }.
