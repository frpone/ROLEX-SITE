Explication simple — Comment fonctionne cette exposition virtuelle

1

La couronne d'entrée

Le logo Rolex est centré sur fond noir avec une légère animation CSS de "respiration" (scale + opacity en boucle). Aucun JS. À remplacer par la vraie vidéo de la couronne quand elle sera hébergée sur le serveur.

2

Le dolly-in (entrée dans la salle)

La vidéo ne se lit pas automatiquement. C'est le scroll qui contrôle la tête de lecture : video.currentTime = progression × video.duration

La scène est un conteneur de calc(100vh + 2400px) de haut. L'intérieur est position: sticky — il reste fixe à l'écran. L'utilisateur scrolle 2 400 px pour traverser toute la vidéo.

  • La vidéo doit avoir : preload="auto" muted playsinline
  • Format recommandé : MP4 (H.264) pour compatibilité universelle
  • Pour héberger : WordPress (Médias) ou dossier OVH via FTP
3

Les affiches cliquables

Une fois le scroll scrub terminé, la page reprend son comportement normal. L'utilisateur peut cliquer sans que rien d'autre ne se passe.

Chaque affiche est un <div> avec cursor: pointer. Au clic, le JS lit les données data-title, data-year, etc. et remplit la lightbox. La lightbox est une couche fixe (position: fixed) qui apparaît par-dessus tout.

  • Pour remplacer un placeholder par une vraie image : <img src="..."> dans .poster-placeholder
  • Pour ajouter une affiche : dupliquer un bloc .poster-card et changer les data-*
  • Pour lier une affiche à une page : remplacer le JS de lightbox par window.location.href = "..."
4

Pour mettre en production (Elementor / Webflow)

Elementor : chaque partie (hero, scroll scene, galerie) devient une section séparée. La vidéo et le JS de scrubbing vont dans un widget "HTML personnalisé". Le JS global dans Custom Code → After </body>.

Webflow : sections normales + Div Block pour les scènes sticky. Embed pour le HTML des vidéos. JS global dans Project Settings → Footer Code.
