Note d'implémentation — Pour Elementor & Webflow

Chaque vidéo (.scroll-video) est contrôlée par le scroll : video.currentTime = progress × video.duration. La progression va de 0 (vidéo hors écran en bas) à 1 (vidéo visible à 30% du viewport).

Elementor : Insérer un widget "HTML personnalisé" et y coller les balises <video> + le bloc <script> ci-dessous. Ajouter class="scroll-video" à chaque vidéo.

Webflow : Ajouter un élément Embed avec les mêmes balises. Le script peut aller dans Project Settings → Custom Code → Footer.

Important : les vidéos doivent avoir preload="auto", muted et playsinline. Sans preload="auto", le scrubbing ne fonctionne pas.
