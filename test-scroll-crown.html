Notes d'implémentation — Pour le webmaster

1 — Scroll scrubbing (vidéos contrôlées par le scroll)

Chaque vidéo avance image par image selon le scroll : video.currentTime = progression × video.duration

La scène a une hauteur de calc(100vh + 2400px). L'intérieur est en position: sticky; height: 100vh. 2 400 px de scroll pour 60 frames = 40 px par frame → fluide et contrôlable.

Attributs obligatoires : preload="auto"  ·  muted  ·  playsinline — sans preload="auto" le scrubbing ne fonctionne pas.

Elementor : widget "HTML personnalisé" pour le HTML des vidéos. Script dans Elementor › Personnalisation › Custom Code › After </body>.

Webflow : Div Block + Embed pour le HTML. Script dans Project Settings › Custom Code › Footer Code.

2 — Thumbnails gelées sur le dernier frame

Les miniatures sont des <video> sans lecture. Le JS place la tête de lecture sur le dernier frame après chargement : video.currentTime = video.duration - 0.1. Le navigateur affiche ce frame comme une image fixe.

3 — Ligne d'invitation au scroll (CSS pur — aucun JS)

Un segment sombre descend en boucle sur une fine ligne claire. S'utilise entre chaque section pour guider l'œil sans créer de vide.

/* ── HTML à coller ── */
<div class="scroll-invite">
  <span class="scroll-invite-label">Scroll</span>
  <div class="scroll-invite-line"></div>
</div>

/* ── CSS à ajouter dans la feuille de style ── */
.scroll-invite {
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 12px;
}
.scroll-invite-label {
  font-size: 9px;
  letter-spacing: 0.35em;
  text-transform: uppercase;
  color: #aaa;
}
.scroll-invite-line {
  width: 1px;
  height: 64px;
  background: #e0e0e0;
  position: relative;
  overflow: hidden;
}
.scroll-invite-line::after {
  content: '';
  position: absolute;
  top: 0; left: 0;
  width: 1px;
  height: 40%;
  background: #1a1a1a;
  animation: scrollDown 1.6s cubic-bezier(0.4,0,0.2,1) infinite;
}
@keyframes scrollDown {
  0%   { transform: translateY(-100%); opacity: 0; }
  20%  { opacity: 1; }
  80%  { opacity: 1; }
  100% { transform: translateY(300%); opacity: 0; }
}
