Note d'implémentation — Pour Elementor & Webflow

Chaque vidéo est contrôlée par la formule : video.currentTime = progress × video.duration

La Sticky Scene fonctionne ainsi :

  • Un conteneur parent de height: calc(100vh + 2400px) crée la zone de scroll
  • L'enfant position: sticky; top: 0; height: 100vh reste fixe à l'écran
  • Le JS calcule la progression : scrolled / (sceneHeight - viewportHeight)
  • 60 frames sur 2400px = ~40px de scroll par frame → animation fluide

Thumbnails : trop petites pour le scrub — elles sont en autoplay loop simple.

Elementor : widget "HTML personnalisé" pour chaque scène + script en pied de page via Elementor → Personnalisation → Custom Code → Footer.

Webflow : Div Block avec overflow visible + Embed pour le script dans Project Settings → Custom Code → Footer Code.
