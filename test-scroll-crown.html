Notes d'implémentation — Pour le webmaster

1 — Scroll scrubbing (vidéos contrôlées par le scroll)

Chaque vidéo avance image par image selon la position du scroll. Formule : video.currentTime = progression × video.duration

La scène a une hauteur de calc(100vh + 2400px). L'intérieur est en position: sticky; height: 100vh — il reste fixe. Le scroll parcourt 2400px pour 60 frames = 40px par frame → animation fluide et contrôlable.

Attributs obligatoires sur chaque <video> : preload="auto"  ·  muted  ·  playsinline

Dans Elementor : widget "HTML personnalisé" pour le HTML des vidéos. Le script va dans Elementor → Personnalisation → Custom Code → After </body>.

Dans Webflow : Div Block + Embed pour le HTML. Le script va dans Project Settings → Custom Code → Footer Code.

2 — Thumbnails fixées sur le dernier frame

Les miniatures sont des balises <video> sans autoplay. Le JS attend que les métadonnées soient chargées, puis place la tête de lecture sur le dernier frame : video.currentTime = video.duration - 0.1. Le navigateur affiche ce frame comme une image statique.

3 — Ligne d'invitation au scroll (CSS pur, aucun JS)

Un segment sombre descend en boucle sur une fine ligne claire. Voici la démo en direct et le code complet à copier :

CSS pur, aucune dépendance.

/* ── HTML ── */
<div class="scroll-invite">
  <span class="scroll-invite-label">Scroll</span>
  <div class="scroll-invite-line"></div>
</div>

/* ── CSS ── */
.scroll-invite {
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 12px;
}
.scroll-invite-label {
  font-size: 9px;
  letter-spacing: 0.35em;
  text-transform: uppercase;
  color: #aaa;
}
.scroll-invite-line {
  width: 1px;
  height: 64px;
  background: #e0e0e0;
  position: relative;
  overflow: hidden;
}
.scroll-invite-line::after {
  content: '';
  position: absolute;
  top: 0; left: 0;
  width: 1px;
  height: 40%;
  background: #1a1a1a;
  animation: scrollDown 1.6s cubic-bezier(0.4,0,0.2,1) infinite;
}
@keyframes scrollDown {
  0%   { transform: translateY(-100%); opacity: 0; }
  20%  { opacity: 1; }
  80%  { opacity: 1; }
  100% { transform: translateY(300%); opacity: 0; }
}

Dans Elementor : widget "HTML personnalisé" → coller le HTML + un widget "CSS personnalisé" (ou ajouter le CSS dans Apparence → Personnaliser → CSS additionnel).

Dans Webflow : Embed pour le HTML, et le CSS dans Project Settings → Custom Code → <head> entre balises <style>.
